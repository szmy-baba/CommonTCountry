## Hosting & Deployment Strategy
The app will be hosted and deployed online using Render. Render supports Java Spring Boot applications and allows us to deploy our project directly from our GitHub repository. The website will have a public URL, allowing users to access CommonTCountry through their web browsers without installing any software.
