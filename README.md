# CommonTCountry
Application description : 
CommonTCountry is an application that match two different countries randomly and present the common things between these countries. This app is mainly for entertaining and learning where the user spend some time to learn about different countries. He can also choose selectively the 02 countries that he wants to learn about. There will be a timer quiz for the user to respond to check his knowledge. The application we be available on a web server and on a mobile phone IOS and ANDROID.
